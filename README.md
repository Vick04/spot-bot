# SPOT-BOT

Fresh start. Building from scratch.

## Setup

```bash
npm install
npm start
```

Server runs on http://localhost:3131

## API Endpoints

- `GET /api/health` - Health check
- `GET /api/status` - Bot status
- `GET /api/gainers` - Top gainers in 1 hour

## WebSocket

Connect to: `ws://localhost:3131`
